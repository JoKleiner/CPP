# C++ – CPP00 to CPP04 - 42 Project
**About:**<br/>
This project is a set of exercises (CPP00–CPP04) to learn the basics of modern C++.<br/>
Each module focuses on specific C++ concepts like classes, inheritance, memory handling, and operator overloading.<br/>

**Modules Overview:**<br/>
**CPP00**<br/>
Basics of classes and objects<br/>
Member functions and attributes<br/>
Constructors and destructors<br/>
std::string, iostream<br/>

**CPP01**<br/>
File streams (ifstream, ofstream)<br/>
More constructors<br/>
Dynamic memory and pointers<br/>
Reference vs value<br/>

**CPP02**<br/>
Orthodox Canonical Form<br/>
Operator overloading (=, <<)<br/>
Fixed-point numbers (custom class)<br/>

**CPP03**<br/>
Inheritance and polymorphism<br/>
Base and derived classes<br/>
Virtual functions<br/>
Deep copies<br/>

**CPP04**<br/>
Abstract classes<br/>
Interfaces and pure virtual functions<br/>
Polymorphism in practice<br/>
Memory management with new, delete<br/>
